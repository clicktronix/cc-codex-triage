# Hygiene 0.8 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close six state-hygiene gaps surfaced by a 2026-07-19 audit of real thread-state dirs across six production repos (marqa agent/platform/analyzer + container root, stokli frontend/backend): gates that never expire, driver state written outside any git repo, `/reply`'s misaligned default thread, `last-error.jsonl` files that outlive their failures, `/cleanup` blind to two stale-state classes, and background dispatches dying to harness process-reaping.

**Architecture:** Five independent, individually-shippable tasks plus a release task. Tasks 1, 2, 4, 5 touch bash (driver / hook / cleanup) and extend the existing regression harnesses (`tests/driver-regression.sh`, `tests/hook-regression.sh`). Task 3 is markdown-only (`reply.md`). Every change is fail-open where it gates existing flows and fail-closed where it writes state — mirroring the house discipline.

**Tech Stack:** bash 3.2 (macOS floor) + POSIX tools, markdown command files, Claude Code plugin manifest JSON.

## Global Constraints

- **Portability:** macOS bash 3.2.57 + Linux; no GNU-only flags without BSD fallback (see `lib.sh:_mtime`).
- **Fail-open on gating, fail-closed on writes:** a malformed/missing `armed_at` must never hard-block a turn; a refused dispatch must never leave partial state.
- **Backward compatible:** armed files written by ≤0.7 (no `armed_at`) keep working — they just don't get TTL treatment; bare `review`/`plan` threads remain reachable by explicit name.
- **Commit convention:** short imperative subjects. **No `Co-Authored-By` trailer, no Claude attribution.**
- **Version:** behavior fixes + additive flags → minor bump `0.7.0 → 0.8.0`.

## Design decisions (resolved defaults — override at plan review)

| # | Decision | Chosen default | Why |
|---|---|---|---|
| D1 | Gate TTL | `armed_at=<epoch>` written at arming; Stop hook treats an armed file older than **14 days** as expired → **auto-disarm** (rm + stderr note naming the file and age), never block. Files without `armed_at`: exempt from TTL (fail-open), `/status` already warns pre-0.5. | The audited hazard is a month-old gate re-firing on a reused branch name; 14d is >2 sprint-lengths for the user's flow. Auto-disarm (not warn-and-block) because a stale gate blocking a turn is exactly the failure being fixed. |
| D2 | No-repo refusal | Driver: when `CLAUDE_PROJECT_DIR` is unset AND `git rev-parse --show-toplevel` fails → **exit 7** with a message naming the cwd and the fix (cd into a repo / set CLAUDE_PROJECT_DIR / use `--oneshot`). `--oneshot` stays allowed (no state written). | The marqa-root incident: state landed in a non-repo container dir AND codex itself refused ("not inside a trusted directory") — the dispatch was doomed anyway; refusing early with a clear message beats stranded state. Exit 7 = next free code (4/5/6 taken). |
| D3 | `/reply` default thread | Same rule as `/review`: `review-<branch-slug>`. Fallback chain when no thread named: slug thread exists → use it; else bare `review` exists → use it WITH a one-line warning ("legacy default thread — consider a per-task thread"); else exit-6 path unchanged. | Aligns the two commands' defaults; keeps old repos working; the warning is the migration nudge. Markdown-only change. |
| D4 | `last-error` lifecycle | Driver: on a **successful** dispatch, `rm -f` the thread's `last-error.jsonl` (the failure it documented is over). On failure, cap the diag to the **last 64 KB** (`tail -c 65536`) — the tail carries the terminal error; a 235 KB full-stream dump was audited. | "last-error" should mean the LAST error; seven stale files (one for a thread that later APPROVEd) were audited. Tail, not head: codex errors terminate the stream. |
| D5 | `/cleanup` new classes | Two additions to `cleanup.sh`: (a) **stale last-error**: `<t>.last-error.jsonl` whose thread has a newer `.log` mtime (the thread recovered) or no `.id` (orphan) → archivable; (b) **dormant threads**: `--older-than <days>` flag lists (dry-run) and archives (`--apply`) whole thread file-sets whose newest file is older than N days. No default age — dormant archiving only when the flag is passed. | Class (a) becomes mostly self-limiting after D4, but existing repos carry pre-0.8 leftovers; (b) productizes the audited manual sweep (June-era threads) without surprising defaults. |
| D6 | Background resilience | New driver flag `--detach`: re-exec the dispatch under `nohup setsid` (fallback plain `nohup` on macOS, where setsid is absent — check `command -v setsid`), child completes and appends to the thread log as usual, parent prints `DETACHED pid=<pid> log=<path>` and exits 0 immediately. `review.md`/`plan.md` `--background` sections: recommend `--detach` and poll the thread log for the new round header instead of holding a harness background process. | The audited failure is harness-side reaping of long dispatches (repeated kills, two sessions). A new-session child survives the parent's kill; the log is already the durable reply channel. |
